# Contributing

Thanks for your interest!

This repository is MIT-licensed, so you're free to use, modify, and fork it.

**I'm not currently accepting direct code contributions (such as pull requests).** If you have an idea or enhancement, I recommend incorporating it into your own fork.

## Forking Encouraged

Forks are welcome and encouraged — take the project in your own direction. No permission is needed beyond the license. If you build something worth sharing, a note or link is appreciated but not required.

## Feedback and Suggestions

Bug reports, ideas, and comments are welcome as issues. I maintain this in my spare time alongside other commitments, so I can't promise to respond to everything or implement every suggestion — but I do read them.
