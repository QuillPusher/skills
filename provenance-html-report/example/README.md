# Example

Open **[output-report.html](output-report.html)** to see what the skill produces.

- `target/`: the document that was checked, a short product overview.
- `source/`: the six files it was written from (Word, PDF, spreadsheet, slides, HTML, Markdown).

All names and data are fictional. The overview contains deliberate mistakes, so the report shows every verdict.

Try it yourself:
